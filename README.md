# MCP Playground

## General

- Model Context Protocol
- Is a spec, like OpenAPI for APIs
- MCP Client <-> MCP Server
- Standardization
- Giving agents access to context, allow executing functions

## Connect MCP Server to your client

1. Enabling MCP support in your tool (IDE, AI coding assistant, etc.)
1. Add config (usually `mcp.json`) to point to MCP server with correct auth if
   needed
